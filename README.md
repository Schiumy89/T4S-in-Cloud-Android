# T4S in Cloud per Android

Canale pubblico di download dell'app T4S in Cloud per i collaboratori
TIME4STREAM. Questo repository contiene soltanto le istruzioni di
distribuzione; non contiene il codice sorgente della Suite o dell'app.

## Scarica l'app

**Versione pilota 0.1.0 (2)**. Richiede **Android 10 o successivo**.

[Scarica l'APK](https://github.com/Schiumy89/T4S-in-Cloud-Android/releases/download/android-v0.1.0-build2/t4s-in-cloud-0.1.0-2.apk)

[Note di rilascio e checksum](https://github.com/Schiumy89/T4S-in-Cloud-Android/releases/tag/android-v0.1.0-build2)

Il download non richiede un account GitHub. Per utilizzare le funzioni
personali dell'app serve un account Suite autorizzato: scaricare l'APK
non crea un account e non concede nuovi accessi o permessi.

## Installazione

1. Scarica l'APK dal link qui sopra sul dispositivo Android.
2. Apri il file e segui le indicazioni di Android per installarlo. Se richiesto,
   autorizza l'installazione da questa specifica sorgente; non disattivare
   Play Protect o altre protezioni del dispositivo.
3. Accedi con il tuo account Suite e completa le verifiche di sicurezza richieste.

Se Android segnala un conflitto di firma o impedisce l'aggiornamento, non
disinstallare l'app per aggirarlo: contatta il referente aziendale prima di
procedere, per preservare i dati locali.
